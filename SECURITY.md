# Security

This repository is an educational, local-first demo. Its API has no application-level
authentication and is disabled by default on non-local hostnames. Do not enable the
public API until the Worker is protected by access control and rate limiting as
described in the README.

To report a vulnerability privately, email [paul@nicia.ai](mailto:paul@nicia.ai).
Please include reproduction steps and the affected commit. We will acknowledge the
report within three business days.
